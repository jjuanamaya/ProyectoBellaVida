# Bella Vida - Guía de Instalación

## Requisitos

- Node.js instalado.
- XAMPP instalado (Apache y MySQL).

## Instalación de la Base de Datos

1. Abrir XAMPP e iniciar Apache y MySQL.
2. Ingresar a http://localhost/phpmyadmin.
3. Crear una base de datos llamada `bellavidanew`.
4. Importar el archivo `bellavidanew.sql` incluido en el proyecto.

## Instalación del Proyecto

1. Ejecutar `instalar.bat` y esperar a que finalice.
2. Ejecutar `iniciar.bat` para iniciar el backend y el frontend.

## Acceso

- Frontend: http://localhost:3000
- Backend: http://localhost:3001

## Tecnologías

React • Node.js • Express • MySQL • JWT • Nodemailer

## Notas

Si el proyecto utiliza un archivo `.env`, copiar el archivo `.env.example` o configurar las variables correspondientes antes de iniciar el backend.
